# MVP Club — logo files

Route **36 · Seal & Line** from the identity board: ring seal + checkmark, wordmark, and the line *Idea to Shipped*.

## Files

| File | Size | Use |
| --- | --- | --- |
| `mvp-club-lockup-color.svg` | vector | Primary lockup. Web, print, anything on a light background. |
| `mvp-club-lockup-black.svg` | vector | One-colour. Faxes, stamps, single-ink print, anywhere colour isn't available. |
| `mvp-club-lockup-white.svg` | vector | Reversed. Dark backgrounds, photos, video lower-thirds. |
| `mvp-club-seal.svg` | vector | Mark alone — app icon, avatar, favicon. |
| `mvp-club-lockup-*.png` | 2100 × 720 | Same three lockups, transparent background. |
| `mvp-club-seal.png` | 1024 × 1024 | Mark alone, transparent. |
| `mvp-club-icon-512.png` | 512 × 512 | App icon / PWA. |
| `mvp-club-icon-180.png` | 180 × 180 | `apple-touch-icon`. |

## Colours

- Ink `#1d1d1f` — seal ring and wordmark
- Emerald `#059669` — checkmark
- Grey `#6e6e73` — tagline only

## Clear space and minimum size

Keep clear space equal to the seal's radius on all sides. Don't set the full lockup below 120 px wide — below that, drop the tagline; below 40 px, use `mvp-club-seal.svg` alone.

## Don't

Recolour the check to anything but emerald or the single ink, stretch the lockup non-proportionally, add effects, or put the colour version on a dark background — use the white file instead.

## Type

The wordmark and tagline reference a system grotesque (Helvetica Neue → Arial fallback), so the SVGs render slightly differently on machines without it. The PNGs are already rasterised and safe to send anywhere. Before this goes to print, the type should be redrawn as outlines in a licensed face — that's the one open item on these files.
